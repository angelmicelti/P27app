Configuración de Firebase requerida

Atención: Esta aplicación necesita Firebase Firestore para funcionar. Sigue estos pasos para configurarla:
  1. Crea un proyecto en Firebase Console
  2. Ve a Project Settings (icono de engranaje) y busca la sección "Firebase SDK snippet"
  3. Copia el objeto firebaseConfig que se muestra
  4. En este archivo HTML, busca la sección FIREBASE CONFIG y reemplaza los valores placeholder
  5. En Firebase Console, activa Firestore Database (modo de prueba o producción)
  6. Si quieres restringir el acceso, configura las Security Rules de Firestore
Estructura esperada del config: 
{
  apiKey: "AIzaSy...",
  authDomain: "tu-proyecto.firebaseapp.com",
  projectId: "tu-proyecto-id",
  storageBucket: "tu-proyecto.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
}
Al guardar el archivo con la configuración correcta, la aplicación detectará automáticamente que está lista y mostrará la pantalla de login.

        ¿Cómo funciona esta aplicación?

        Esta aplicación gestiona los permisos (asuntos propios) del profesorado de un centro educativo.

        📋 Pasos para configurar y usar la aplicación:
        1. Configura el año de inicio del curso

          En la pestaña "Configuración", ajusta el año de inicio del curso escolar (Septiembre).

        2. Añade la lista de profesorado

          Puedes añadir profesores manualmente o importar desde un archivo Excel con la lista.

        3. Configura los días especiales

          Establece festivos locales, provinciales, días no disponibles y días no lectivos.

        4. Gestiona permisos en el calendario

          En la pestaña "Calendario", haz clic en un día para añadir permisos al profesorado.

        5. Consulta informes

          Usa la pestaña "Informes" para ver resúmenes por profesor y exportar PDF.

        6. Guarda tus datos

          Los datos se guardan automáticamente en Firebase Firestore. También puedes exportar/importar en formato JSON.

        🔥 Firebase Firestore

        Los datos se almacenan en la nube de Firebase Firestore. Ventajas:

        • Sincronización automática: Los cambios se reflejan en tiempo real
        • Multiusuario: Varios usuarios pueden trabajar simultáneamente
        • Backup en la nube: Tus datos están seguros en Firebase
        📊 Tipos de permisos disponibles
        • Retribuidos Lectivos: Máximo configurable por profesor (por defecto 2, editable en la configuración del profesorado). Solo en días lectivos.
        • Retribuidos No Lectivos: Máximo 6 por profesor si no usa lectivos; mínimo 4 si usa los 2 lectivos. El total retribuido (lectivos + no lectivos) no puede superar 6. Solo en días no lectivos.
        • No Retribuidos: Sin límite (cualquier día hábil)
